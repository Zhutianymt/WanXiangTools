# 自动化流水线运维工具（万象工具）

进程守护 / 生产环境自动化运维桌面工具，基于 tkinter + 系统托盘。
支持
- **1.进程监控**  
      实时监控关键进程并在异常退出时自动拉起。
- **2.局域网设备管理**  
      扫描局域网内运行本软件的其他设备，支持一键关机和一键唤醒。
- **3.文件同步**  
      选择文件/文件夹发送到局域网内其他运行本软件的设备。
- **4.POST**  
      HTTP POST 请求的编辑、保存、发送与响应查看。
- **5.PLC**  
      读写西门子S7全系列PLC(1200,1500,S7-300,S7-400)数据。
- **6.SQL查询**  
      连接 Oracle 数据库执行 SQL 脚本并查看结果，支持查询终止与超时控制。
- **7.自动化任务**  
      按调度周期从 Oracle 和西门子PLC查询单值，经比较条件判断后自动执行 PLC 点位读写/置位/切换。

## 发行包结构
GitHub Actions 自动构建产出单文件 `万象工具.exe`，`oracle_ic.zip` 保持外置，二者同置于一个 zip 中发布：

```
万象工具-<版本>.zip
├── 万象工具.exe       # PyInstaller --onefile 单文件，含 and all python deps
└── oracle_ic.zip     # 运行时自动解压为 Oracle thick 模式 19c Instant Client
```

程序运行时若同级存在 `oracle_ic.zip`，会自动解压到临时目录并初始化 `oracledb` thick 模式，从而支持 10g/11g 等旧版 Oracle 服务器。
